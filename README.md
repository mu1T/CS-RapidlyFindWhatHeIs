# CS2 Data Stats in Steam Profile (Noob or Forsaken?)

在 Steam 个人资料页（`steamcommunity.com/id/*`、`steamcommunity.com/profiles/*`）上叠加 CS2 选手成分与战绩面板：
支持在资料页侧栏或内嵌卡片中直观展现玩家在 **完美世界竞技平台**、**5E 对战平台**、**FACEIT**、**Leetify**、**CSStats** 的段位、评分、比赛记录与封禁状态，并支持 **CSQAQ / SteamDT** 饰品库存人民币估值与各平台行情对比。

> **版本**：v1.12.6（以同目录下 `manifest.json` 中的 `version` 为准）  
> **运行架构**：WebExtension Manifest V3 原生架构，Chromium 内核浏览器（Chrome、Edge 等）免依赖即装即用。

## 📌 代码混淆与明文范围说明

本目录代码的混淆与明文分布如下：

### 1. 存在混淆与白盒加固的部分
- **5E 对战平台**：HMAC 网关请求签名计算（采用白盒预计算初始向量折叠密钥与纯 JS 32位位运算，彻底消灭运行时明文密钥与 crypto.subtle 依赖）；
- **完美世界竞技平台**：比赛 Demo 下载链接解析（OSS 预签名特征与私有鉴权尾串）。

### 2. 无混淆（纯明文源码）的部分
- **公开平台接口**：Leetify、FACEIT、CSQAQ、SteamDT、CSStats 等平台的 API 请求、数据解析与聚合计算逻辑，全部为原始明文代码；
- **前端 UI 与交互渲染**：所有 content 脚本（页面卡片渲染、五维雷达图、对局折叠面板、比分看板、浮窗、模式过滤、自愈跳转等）以及 options 设置页，全部为原始明文代码；
- **基础架构与缓存管理**：后台 Service Worker 消息分发、统一面板缓存机制、版本同步等基础架构代码，全部为原始明文代码。

### 3. 数据脱敏
- 代码中的内置展示保护名单已清洗为**空数组**（`const F5E_CONTACT_DENY = [];`）。

## 🚀 安装与使用教程（无需安装 Node/npm）

本目录是一个**原生、自包含、零外部构建依赖**的 WebExtension 源码目录，支持在常用浏览器或 Steam 客户端内置浏览器中直接加载运行：

### 方法一：常规网页端浏览器（Chrome / Edge 等）
1. 打开 Chrome 或 Edge 浏览器，访问扩展程序管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 在右上角开启 **「开发者模式」**（Developer Mode）；
3. 点击左上角的 **「加载已解压的扩展程序」**（Load unpacked）；
4. 选择**本目录**（即包含 `manifest.json` 的这层目录）；
5. 打开任意 Steam 社区个人资料页（如 `https://steamcommunity.com/profiles/...` 或 `https://steamcommunity.com/id/...`），战绩面板将自动挂载展示；
6. 点击浏览器工具栏扩展图标 → **「扩展程序选项」**，即可自由配置显示模式（原生/展柜/分体）、透明度、各平台开关与缓存策略。

### 方法二：Steam 客户端内置浏览器
1. 打开 Steam 客户端，进入自己的个人资料页面；
2. **按住 Ctrl 键的同时，鼠标左键点击「编辑个人资料」**，Steam 客户端会弹出一个内置浏览器窗口；
3. 在弹出的浏览器窗口顶部导航栏处输入 `chrome://extensions` 并按回车；
4. 在打开的扩展页面右上角开启 **「开发者模式」**；
5. 将插件压缩包（.zip / .crx）或解压文件夹直接拖入该窗口即可安装完成；
   > 详细操作图文步骤可参照小黑盒社区教程：https://www.xiaoheihe.cn/app/bbs/link/941f71705379

## 🛡️ 隐私与数据说明

1. **凭证隔离与本地化**：
   - 插件**不收集、不上传**用户的任何账号密码或个人凭证；
   - 用户自备填写的平台 Token 均保存在浏览器本地的 `chrome.storage.local` 中，仅在发起对应平台自身请求时直接发送给官方服务器。
2. **零跨域上传与零数据打点**：
   - 插件没有自建后端服务器，不存在中心化数据统计或行为打点。
